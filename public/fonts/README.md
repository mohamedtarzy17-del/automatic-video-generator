# Fonts

Drop your `.ttf` or `.woff2` font files here.

## Recommended Fonts

| Font | Style | Download |
|------|-------|----------|
| **Montserrat** | Clean, modern headings | [Google Fonts](https://fonts.google.com/specimen/Montserrat) |
| **Bebas Neue** | Bold cinematic titles | [Google Fonts](https://fonts.google.com/specimen/Bebas+Neue) |
| **Poppins** | Versatile, rounded | [Google Fonts](https://fonts.google.com/specimen/Poppins) |
| **Inter** | Clean body text | [Google Fonts](https://fonts.google.com/specimen/Inter) |
| **Playfair Display** | Elegant serif | [Google Fonts](https://fonts.google.com/specimen/Playfair+Display) |
| **Oswald** | Condensed impact | [Google Fonts](https://fonts.google.com/specimen/Oswald) |

On each Google Fonts page, click **"Download family"** (top right), unzip, and place the `.ttf` files here.
