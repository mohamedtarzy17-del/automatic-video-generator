# SFX Assets

Drop your sound effect files here. Supported formats: `.mp3`, `.wav`

## Required Files

| Filename | Type | Used For |
|----------|------|----------|
| `pop.mp3` | Short pop/click | Card & element appearances |
| `whoosh.mp3` | Swoosh/transition | Scene transitions |
| `typing.mp3` | Keyboard typing | Text reveals |
| `rise.mp3` | Rising tone/shimmer | Stats, counters, numbers |
| `ambient.mp3` | Sci-fi ambient pad | Background loop (entire video) |

## Free Sources

- [Pixabay SFX](https://pixabay.com/sound-effects/) — free, no attribution
- [Freesound.org](https://freesound.org/) — large free library
- [Mixkit](https://mixkit.co/free-sound-effects/) — free, high quality

> Files will be auto-detected by the SFX system. Only sounds that exist will play — missing files are silently skipped.
